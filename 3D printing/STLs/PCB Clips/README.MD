This is the STL file for a 3D printed PCB clip. Note that only the right side is provided. Left side can be created in the 3D print utility by copying and mirroring the right side clip. We recommend using UltimakerCura. 

***IMPORTANT***
This particular clip only works with WiLoV1. For V2, a new STL must be generated. See WiLo/3D printing/Fusion 360/PCB Clip/Source

Print settings:
    - Material: PETG (Stronger than PLA. PLA+ or ABS might work too.)
    - Infill: 100%
    - Supports: None
    - Print temperature: 235 C
    - Build Plate Temperature: 85 C
    - Layer Height : 0.2mm
